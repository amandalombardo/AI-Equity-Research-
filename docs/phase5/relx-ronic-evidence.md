# RELX: terminal return on new investment (RONIC) evidence (14 Oct 2026)

RONIC is the return RELX earns on money it reinvests after FY30. The engine uses it to set how much RELX must reinvest to grow 2.0% a year forever: reinvestment = growth / RONIC. A higher RONIC means less reinvestment and more cash to shareholders. Same method as Diageo (13.4%), Coca-Cola (27.0%) and Unilever (17.8%), each based on the company's own reported ROIC.

| Evidence | Value | Source |
|---|---|---|
| RELX's reported ROIC, FY21 to FY25 | 11.9%, 12.5%, 14.0%, 14.8%, **15.4%** | AR25 p.186; FY25 results p.14 |
| How RELX measures it | after-tax adjusted operating profit / invested capital **including all goodwill and acquired intangibles at original cost** | FY25 results p.14 |
| ROIC on book capital employed (FY25) | 25.1% (2,590 / 10,322, computed) | FY25 results p.13-14 |
| Return on the extra capital added FY21-25 | about 47% (NOPAT +£792m on +£1,691m invested capital, computed) | same sources |

- RELX's own 15.4% is the cautious measure: it charges every pound ever paid for acquisitions.
- The 47% on recent extra capital is flattered by rising margins and pricing on existing products, so it is not a reliable forever rate.
